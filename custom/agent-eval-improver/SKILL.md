# Agent Eval Improver

## Overview

Systematic evaluation of agent outputs against defined dimensions of thoroughness, autonomy, and effectiveness, followed by concrete improvement recommendations.

## Core Dimensions

- Thoroughness: coverage of requirements, edge cases, verification steps
- Autonomy: degree of human intervention required
- Effectiveness: correctness, completeness, and usefulness of the final output

## Protocol

1. Define or load evaluation criteria for the current task.
2. Score the recent output(s) on each dimension with evidence.
3. Identify the highest-impact failure modes or gaps.
4. Recommend specific skill extensions, process changes, or prompt improvements.
5. Optionally draft the recommended skill or checklist.
